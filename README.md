## 它解决的问题很小：光标移开，屏幕就暗下来

ScreenFocus 由 Apptorium 开发，是一个纯粹的 Mac 小工具。默认状态下它只调暗侧边屏幕，主屏不动；你可以改设置，决定哪几块屏参与变暗。所有可调项就这五个：

- 调暗程度，也就是屏幕最终暗到什么程度
- 哪些显示器参与调暗
- 淡入时长，光标移开时变暗的过渡速度
- 淡出时长，光标回来时恢复的速度
- 触发延迟，光标离开后等多久开始变暗

默认只暗侧屏、不需要按任何键，这两点是它跟普通亮度调节工具最实际的区别。你不需要记得去开什么，它自己判断。

MacUpdate 上记录的版本是 1.1，这一版换了新的授权系统，加了 Apple Silicon 原生支持，图标也重画了。原生支持这点对 M 系列 Mac 用户有意义，说明它不再靠转译跑。系统要求是 macOS 10.12 或更高，门槛很低，近七八年的 Mac 都在范围内。开发者声明这款软件不收集任何数据，这一点在 App Store 的隐私说明里写得很明白。

有两点要先接受。界面只有英文，菜单和设置项都是英文的，好在选项只有上面那五个，查一次字典就够。功能边界也很窄，它就是自动调暗屏幕，不做别的。你的痛点如果是晚上整体太刺眼，macOS 自带的夜览和亮度调节更直接，用不着为这个装东西。

## 缺点，以及它冷门到什么程度

先说最实际的一条：你几乎找不到可信的第三方评测。MacUpdate 上这个软件的页面挂在那里很多年，用户评价至今是 0 条。App Store 上它也是个长尾工具，没有成规模的媒体测评或者论坛长帖。

这意味着两件事。好处是它没有被过度营销，你看到的描述就是它能做的全部；坏处是出问题时没人替你踩过坑，遇到兼容性毛病只能直接找开发者。买这种冷门工具，某种程度上是在赌开发者的响应速度。

第二条是自动触发的双刃剑。光标一移开就变暗，在读文档、写代码时是优点；但在需要频繁在几块屏之间来回扫视的工作里，比如盯盘或者剪多轨，副屏一暗一亮的过渡会打断节奏。延迟和淡入时长都能调，调到不碍事需要花点时间试，不是装完就完事。

第三条是授权的可迁移性。App Store 版跟 Apple ID 绑定，换机这件事不用操心；国内渠道买的授权码，能激活几台、换机是否免费重发，得看页面条款，别默认「买断」等于「以后什么都不用管」。版本更新方面，App Store 版的更新由开发者推送，走 Apple ID 那套机制；授权码版的升级范围同样以商品页说明为准。

第四条是语言。全英文界面，对多数人影响有限，但如果你的英文实在吃力，设置项里「延迟」「淡入」这些词还是得查一下。
